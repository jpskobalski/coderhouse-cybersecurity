# Capturas requeridas

Esta carpeta debe contener únicamente evidencia de la máquina virtual de Windows utilizada para la práctica.

| Archivo | Debe mostrar |
| --- | --- |
| `01-usuario-estandar.png` | El usuario creado y su clasificación como Usuario estándar. |
| `02-windows-update.png` | Windows Update buscando actualizaciones o informando que el sistema está actualizado. |
| `03-smb1-deshabilitado.png` | La característica SMB 1.0/CIFS desmarcada. |

Antes de tomar cada captura, ocultar contraseñas, correos personales, claves de producto, direcciones IP públicas y cualquier otro dato sensible que no sea necesario para demostrar el control.
